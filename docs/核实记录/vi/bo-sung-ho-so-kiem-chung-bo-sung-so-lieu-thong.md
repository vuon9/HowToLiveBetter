## III. Ghi nhớ về cách lấy dữ liệu
- **Chrome không giao diện không dùng proxy hiện có thể lấy được**: mps.gov.cn (biên bản họp báo), mohrss.gov.cn và chinajob.mohrss.gov.cn, nhc.gov.cn, samr.gov.cn, mva.gov.cn. Các trang này dùng curl vẫn không được.
- **Vẫn chưa lấy được**: 119.gov.cn (WAF của China Telecom, Chrome cũng trả về 405), travel.state.gov và spglobal.com (Cloudflare, file PDF của spglobal lấy qua bản lưu trữ archive.org), SAGE và wemjournal (Cloudflare).
- Trang bài viết của nfra.gov.cn render ở phía frontend, nhưng API dữ liệu `/cn/static/data/DocInfo/SelectByDocId/data_docId=<id>.json` có thể lấy trực tiếp nội dung chính.
- Trang mem.gov.cn khi dùng curl phải thêm `--compressed`.
